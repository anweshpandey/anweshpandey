# Set up your GitHub profile README

This starter is customized for Anwesh Pandey using the supplied CV and the sample profile repository as visual inspiration. It uses original SVG banner artwork and a rewritten profile layout; it does not copy the sample owner's personal claims or projects.

## 1. Create the special profile repository

1. On GitHub, create a **public** repository named exactly `anweshpandey` (the username of the connected GitHub account).
2. Make sure the repository name exactly matches the username.
3. Upload the contents of this ZIP to the repository root, including the hidden `.github` folder.
4. Commit to the default branch (usually `main`).

GitHub will display `README.md` on your profile at `https://github.com/anweshpandey`.

## 2. Enable the contribution snake

In the repository, open **Settings → Actions → General → Workflow permissions** and allow workflows to have read/write permissions if required. Then go to **Actions → Generate contribution snake → Run workflow**. The workflow publishes the generated SVGs to an `output` branch.
